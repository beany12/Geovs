# Audio Files — GeoVs

Place royalty-free MP3 files here. Recommended sources: Pixabay, Freesound, Uppbeat.

## Music (`music/`)
- `menu.mp3` — Ambient menu/lobby track (looping, chill)
- `gameplay.mp3` — In-game background track (looping, upbeat)
- `tense.mp3` — Timer running low track (looping, tense)

## Sound Effects (`sfx/`)
- `click.mp3` — Button click (short, subtle)
- `navigate.mp3` — Screen transition (whoosh/swipe)
- `correct.mp3` — Correct answer (bright chime)
- `wrong.mp3` — Wrong answer (buzzer/error tone)
- `timer-warn.mp3` — Timer warning <10s (tick/alarm)
- `victory.mp3` — Round/game won (fanfare)
- `defeat.mp3` — Round/game lost (sad tone)
- `streak.mp3` — Streak increment (ascending chime)
- `levelup.mp3` — Level up (triumphant jingle)
- `achievement.mp3` — Achievement unlocked (special chime)
- `confetti.mp3` — Celebration moment (party popper)
- `countdown.mp3` — Countdown tick (single tick sound)

Missing files are silently ignored — the game works fine without them.
